# 驗證紀錄

2026-11-13，版本 0.2.0。這是本 repo 的正式驗證與工程進度來源。

## 本輪已完成

- ST7789／ILI9341 交叉編譯通過，工具鏈鎖定 PlatformIO espressif32 6.5.0、Arduino ESP32 2.0.14、TFT_eSPI 2.5.43。
- C++ 測試涵蓋 CYD1 格式／CRC、清單、完整等比例顯示、方向、手勢、Wi-Fi 名稱與密碼邊界、重連排程與計時器溢位。
- Python 測試涵蓋錯誤晶片／容量、分割表不符、備份未完整時拒絕寫入、app-only 位址限制及 USB 圖片校驗。
- 瀏覽器模擬 API 整合測試通過：桌面／手機排版、完整圖片邊緣保留、編解碼、切圖、設定、排序、刪除、混合橫直上傳與失敗恢復。
- 新增 Wi-Fi 設定／狀態／忘記流程的瀏覽器測試；提交後清空密碼欄，回傳的網路狀態不含家用 Wi-Fi 密碼。
- 公開預覽與測試只使用自製幾何圖。使用者照片、私有驗證日誌、硬體身分與 Flash 備份未納入公開 repo。
- 公開 repo 首輪 [GitHub Actions](https://github.com/MAXXTANG/cyd-photo-frame/actions/runs/43406339747) 的 firmware-and-host 與 browser 工作均通過，包含乾淨 Linux 環境的兩板型編譯與空白圖片區建置。

## 先前版本的實機證據

0.1.3 已在雙 USB ST7789 CYD 上完成 app-only 更新、六張圖片開機 CRC 校驗，以及橫式 320×240／直式 240×320 切換。使用者確認長按切換自動／手動、短點換圖正常，橫圖從原圖重製後較清楚。這些是 0.1.3 的驗收，不取代 0.2.0 家用 Wi-Fi 功能驗收。
